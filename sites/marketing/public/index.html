Free forever. Open source, MIT.

Keep Cooking costs $0 — there is no premium tier and no subscription. The code is MIT licensed on GitHub: permissive, not copyleft. Fork it, host it yourself, even sell hosting — keep your changes private if you want.

  • Not AGPL like Mealie, Tandoor, KitchenOwl, or RecipeSage
  • Not source-available with Commons-Clause or dual-license riders
  • Not sub-locked like Paprika 4 Premium ($14.99/yr)

Runs on the Cloudflare free tier — one Worker, one D1 database, one R2 bucket. Deploy your own backend in minutes: wrangler d1 create + r2 bucket create + deploy.

Questions, answered

Who owns my recipes?

You do. Your library exports anytime to JSON, Markdown, or self-contained HTML with Schema.org markup. No lock-in, no export fees.

How does sync work?

iPhone and iPad sync natively and share with your household; cookbooks can be shared too. Everything is offline-first — edits queue locally and converge when you're back online.

Can I export or leave?

Yes, anytime: one-tap export to JSON, Markdown, or HTML. Your data is yours, in open formats.

Can I self-host or fork it?

Yes. The code is MIT licensed — run the Cloudflare Worker + D1 + R2 backend yourself, fork the app, or sell hosting. No copyleft, no permission needed.

What's the catch — how is it free?

No catch: it's a permissive open-source project, not a venture-backed subscription funnel. Hosting fits in Cloudflare's free tier, so running it costs the project ~$0.

Does it work on Android and the web?

Yes — native iOS (iPhone + iPad, with Share Sheet, widgets, Shortcuts, and Apple Watch), Android, and the web app at /app.
